## 히어로 섹션 반응형 웹 구현

첨부한 이미지 2장은 순서대로 데스크탑과 모바일 화면입니다. 두 이미지를 분석하여 레이아웃, 요소 배치, 크기, 간격, 타이포그래피를 최대한 유사하게 구현해 주세요.
실제로 사용된 이미지는 images/used 폴더에 있는 이미지를 사용해주세요.

### 1. 기본 레이아웃
- 히어로 섹션은 화면 전체를 차지하는 `100vh` 높이로 구성합니다.
- 히어로 배경은 이미지로 처리하며, `background-size: cover`를 기본으로 사용합니다.
- 배경 이미지 위에 왼쪽 하단 기준으로 제목과 설명 텍스트를 배치합니다.
- 텍스트 가독성을 위해 배경 하단에 자연스러운 어두운 그라데이션을 적용합니다.

### 2. 고정 UI 요소
- 상단 내비게이션은 `position: fixed`로 화면 상단에 고정합니다.
- 오른쪽 중앙의 세로 슬라이드 인디케이터도 화면에 고정합니다.
- 오른쪽 하단의 원형 플로팅 버튼 2개 역시 화면에 고정합니다.
- 고정 요소들은 히어로 배경과 독립적으로 배치하고 적절한 `z-index`를 적용합니다.

### 3. 반응형 레이아웃
- **Desktop First** 방식으로 작성합니다.
- 데스크탑: 769px 이상
- 모바일: 768px 이하 (`@media (max-width: 768px)`)
- 화면 크기에 따라 단순 축소하지 않고, 참조 이미지에 맞게 요소 배치와 구성을 변경합니다.

### 4. 모바일 전환
- 데스크탑의 로고 및 우측 유틸리티 메뉴는 숨기고, 상단에는 카테고리 메뉴만 표시합니다.
- 카테고리 메뉴는 상단 가로 정렬을 유지합니다.
- 화면 하단에 모바일 전용 고정 내비게이션 바(카테고리, 검색, 홈, 장바구니, 마이)를 표시합니다.
- 히어로 배경은 모바일 전용 이미지를 사용하며, 인물 중심으로 화면을 채웁니다.
- 제목과 설명은 모바일 화면의 왼쪽 하단에 맞춰 재배치하고 크기를 조정합니다.
- 오른쪽 슬라이드 인디케이터와 플로팅 버튼은 유지하되, 모바일 화면에 맞게 위치와 크기를 조정합니다.
- 텍스트와 플로팅 버튼이 하단 내비게이션에 가려지지 않도록 배치합니다.

### 5. 구현 조건
- CSS는 Desktop First 방식의 `max-width` 미디어쿼리를 사용합니다.
- 데스크탑과 모바일 배경 이미지는 별도로 지정할 수 있도록 구성합니다.
- 고정 UI와 히어로 콘텐츠를 구조적으로 분리합니다.
- 아이콘은 가능한 SVG 또는 아이콘 라이브러리를 사용합니다.
- 가로 스크롤이 발생하지 않도록 처리합니다.
- HTML, CSS, JavaScript를 역할에 맞게 분리하고 기존 프로젝트의 코드 구조와 명명 규칙을 유지합니다.

[ 이어진 수정 프롬프트 #2 - 모바일 햄버거 메뉴]

기존 사이트에 첨부 시안을 기준으로 모바일 메뉴를 구현해줘. 첫 번째 이미지는 메뉴가 열린 상태, 두 번째 이미지는 닫힌 상태야.

상세 이미지 경로는  ./images/menu/gdwebicon.jpg/ 야.

- **기본 상태:** 기존 화면의 상단 로고와 오른쪽 `MENU` 버튼을 유지해줘.
- **메뉴 열기:** `MENU` 클릭 시 검정 배경의 전체 화면 메뉴가 화면 위쪽에서 아래로 슬라이딩하며 나타나고, 버튼은 `CLOSE`로 변경돼.
- **메뉴 닫기:** `CLOSE` 클릭 시 메뉴가 아래에서 위로 슬라이딩하며 사라지고, 기존 화면과 `MENU` 버튼이 다시 보여야 해.
- **레이어 구성:** 메뉴는 `position: fixed`로 뷰포트 전체를 덮고, 본문·오른쪽 인디케이터·SNS 버튼보다 위에 표시해줘. 상단 로고와 열기·닫기 버튼은 같은 위치를 유지하며 항상 조작 가능해야 해.
- **메뉴 디자인:** `HOME`, `WORKS`, `LAB.X`, `CONTACT`를 큰 흰색 글자로 왼쪽 상단에 세로 배치해줘. 그 아래에는 수상 문구와 마크를 배치하고, 하단의 넓은 여백은 시안대로 유지해줘. 로고는 **Anta**, 영문 메뉴와 수상 문구는 **DM Sans**를 사용해줘.
- **애니메이션:** 메뉴 패널의 `transform: translateY(-100%)`와 `translateY(0)`을 전환하고, 약 400ms의 부드러운 easing을 적용해줘. 닫기 애니메이션이 끝난 뒤 숨김 처리하며, 빠르게 반복 클릭해도 동작이 끊기거나 상태가 꼬이지 않게 해줘.
- **스크롤과 이동:** 메뉴가 열리면 배경 스크롤을 잠그고, 닫으면 기존 스크롤 위치를 유지해줘. 메뉴가 화면보다 길면 메뉴 내부에서 스크롤할 수 있게 하고, 항목 클릭 시 메뉴를 닫은 뒤 해당 섹션으로 이동해줘.
- **반응형:** 데스크톱 스타일을 기본으로 작성하고, `max-width: 1199px`에서 태블릿용 `MENU` 방식으로 전환해줘. 그 아래에 `max-width: 806px` 모바일 스타일을 작성해 첨부 시안의 간격과 글자 크기를 적용해줘. 데스크톱으로 전환하면 열린 메뉴와 스크롤 잠금도 해제해줘.
- **접근성:** 열기·닫기는 실제 버튼으로 구현하고, `aria-expanded`를 상태와 동기화해줘. 열린 메뉴 내부에서 키보드 포커스를 유지하고, `Esc`로 닫으면 `MENU` 버튼으로 포커스를 돌려줘. 닫힌 메뉴는 클릭과 키보드 탐색 대상에서 제외해줘.
