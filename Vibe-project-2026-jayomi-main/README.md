# DRAFT.X 웹사이트 구현

> 타깃 사이트: https://draftx.co.kr/ (DRAFT.X · 드래프트엑스, 하이엔드 디지털 에이전시)
> 스택: HTML5 / CSS3 / Vanilla JavaScript (ES2022+) — 프레임워크·빌드 도구 없음
> 작업을 시작할 때 이 문서를 읽은 뒤, 반드시 `task-history/task.md`를 확인해 이전 작업과 다음 단계를 파악합니다.

---

## 1. 시작 전에 읽을 것 (순서대로)

1. **`task-history/task.md`** — 이전 작업 요약과 미완료·다음 작업을 확인합니다. 파일이 없으면 기존 이력 없이 진행하고, 작업 완료 후 필요하면 생성합니다.
2. **`spec-kit/AGENTS.md`** — 이 프로젝트의 디자인·개발 규약 전체.
   - PART 1·2는 일반 규칙, **PART 3(SITE SPECIFIC)이 draftx.co.kr 전용 규칙이며 충돌 시 PART 3이 우선**합니다 (접근성·보안 제외).
   - 작업을 끝내기 전에 문서 끝의 **PART 4 체크리스트**를 통과시킵니다.
3. `css/tokens.css` — 디자인 토큰. 이미 있으면 먼저 읽고, 없으면 `AGENTS.md` PART 3 §S3~S5의 토큰으로 만듭니다.
4. 기존 컴포넌트·모듈 — 새로 만들기 전에 재사용할 수 있는지 확인합니다.

`spec-kit/` 폴더는 **규약·명세 문서 보관용**이며 배포 대상이 아닙니다. 이 폴더의 파일은 사용자가 요청하지 않는 한 수정하지 않습니다. 규약을 바꿔야 할 것 같으면 변경안을 제안하고, 사용자가 승인하면 `AGENTS.md`의 변경 이력에 기록합니다.

## 2. 반드시 지킬 핵심 사항

### 값의 신뢰 등급

`AGENTS.md` PART 3의 값에는 등급이 붙어 있습니다.

| 표기 | 의미 | 에이전트의 행동 |
|---|---|---|
| ✅ 확인 / ✅ 실측 | 원본 사이트·Figma 시안에서 직접 읽은 값 | 그대로 사용 (반올림·임의 보정 금지) |
| 🧮 계산 | 실측 값에서 환산한 값 | 그대로 사용 |
| 🔶 임시 | 모바일·태블릿·헤더·모션 타이밍·호버 등 확인하지 못한 값 | 임시값으로 구현하되 **"사이트의 실제 값"이라고 보고하지 않음** |

- 실측 값은 **시안(Figma 1440px 데스크톱 프레임) 기준**입니다. 보고할 때도 "시안 기준 값"이라고 씁니다.
- 값은 `tokens.css`에서만 바꾸고 **토큰 이름은 바꾸지 않습니다.**

### 구조 규칙

- 페이지 골격은 **겉박스(`.outer-box`) > 속박스(`.inner-box`) > 파티션 박스(`.part-box`, flex) > 내용 박스** 구조입니다 (PART 3 §S2). 페이지 골격에 Grid를 쓰지 않습니다.
- `.container`, `.wrapper`, `.row`, `.col` 같은 동의어 클래스를 만들지 않습니다.
- 파일·폴더명은 kebab-case. 예: `/lab.x` → `pages/lab-x.html`.

### 이 사이트의 특징 (일반 규칙의 예외)

- **다크 테마**: 배경 `#000000`, 글자 `#ffffff`, 포인트 연두 `#82ff2e`(중괄호·푸터 이메일·요금 강조 카드 3곳에만).
- **서체 4종**: DM Sans(주), Anta(`DRAFT.X` 워드마크 전용), Manrope(중괄호 전용), 한글 본문(Pretendard, 🔶).
- **캡션 표기 허용**: `© 라벨`, `( 괄호 )`, `{ 중괄호 }`, `//`, `—` 패턴은 원본에 있는 자리에만 씁니다.
- **모션은 8종만**: 인트로, 단어별 리빌, 시차 이미지, 아코디언, 요금 카드 상태, 버튼 글자 모션, 블렌드, 아카이브 트랙 (PART 3 §S6.14). 모두 `prefers-reduced-motion`에서 최종 상태로 즉시 표시하고, 자동 이동에는 일시정지 버튼을 둡니다.

### 하지 말 것

- 원본에서 같은 문구·푸터가 2~3번 반복되는 것은 Framer 산출물입니다. **복제하지 않고 한 번만** 씁니다.
- 원본에 없는 문구·가격·강조색·섹션을 지어내지 않습니다. 문구가 필요하면 사용자에게 요청합니다.
- 요청하지 않은 라이브러리·CDN·폰트를 추가하지 않습니다. 필요하면 이유와 함께 먼저 제안합니다.
- Framer 이미지 URL(`framerusercontent.com`)을 핫링크하지 않습니다.
- 중복된 `h1`을 만들지 않습니다. 페이지당 `h1`은 하나입니다.

## 3. 구현 범위

| 페이지 | 파일 | 상태 |
|---|---|---|
| 홈 | `index.html` | 구현 대상 |
| Works | `pages/work.html` | 구현 대상 |
| LAB.X | `pages/lab-x.html` | 구현 대상 (시안 프레임 없음 — 구조·문구만 확인됨) |
| Contact | `pages/contact.html` | 구현 대상 (시안 프레임 없음 — 구조·문구만 확인됨) |
| 작업 상세 | `pages/work/[slug].html` | **사용자가 요청하기 전에는 만들지 않음** (`dra` `muk` `arche` `velo` `otium` `aur-a`) |

**권장 진행 순서**

1. `tokens.css`·`base.css`·`layout.css` (토큰과 박스 구조)
2. 공통 헤더·푸터·카카오톡 채팅 버튼
3. 홈 섹션을 위에서 아래로 (히어로 → 선택 작업 → 쇼케이스 → 제작 방식 → 핵심 철학 → 수상 → 요금 → 아카이브)
4. Works → LAB.X → Contact
5. 모션 (구조가 완성된 뒤 마지막에 추가)
6. PART 4 체크리스트 점검

## 4. 작업 시작 전에 사용자에게 확인받을 것

`AGENTS.md` PART 3 §S7의 🔶 항목 중, **해당 영역을 구현하기 전에** 질문합니다. 한꺼번에 묻지 말고 그 영역에 들어갈 때 묻습니다.

| 영역 | 확인할 것 |
|---|---|
| 시작 전 | 한글 본문 서체(시안 이름 `SansSerif`), 서체 woff2 파일 제공 여부, 이미지 파일(원본 해상도) 제공 여부 |
| 헤더 | 투명/불투명, 높이, 모바일 메뉴 패널 모습 (시안에 헤더 없음) |
| 푸터 | 이메일: 시안 `surpas250@gmail.com` vs 배포 사이트 `draftx.co@gmail.com` — **현재는 배포 사이트 값 사용** |
| 푸터 | `rgba(166,166,166,.6)` 글자 대비 3.5:1(AA 미달) — 승인 시 `#a6a6a6`으로 상향 |
| 히어로 | 인트로 이후 최종 크기·배치, `10+ years`와 다른 곳의 `20 years` 불일치 |
| 수상 | 카운트 `(27)`과 보이는 행 수 불일치, 분류 라벨 |
| LAB.X | `STUDY` 항목 24개의 제목·번호 형식 |
| Contact | 소개 문단·인용문 전문, **폼 전송 방식**(mailto / 폼 서비스 / 서버) |
| 반응형 | 브레이크포인트 실제 전환점, 모바일·태블릿 값 |

사용자가 DevTools로 확인한 값을 전달하면 `AGENTS.md` PART 3의 🔶를 ✅로 교체하고 변경 이력에 기록합니다.

## 6. 작업 완료 보고 형식

완료할 때 아래 4가지를 간결하게 보고합니다 (`AGENTS.md` PART 2 §8.3).

1. **무엇을 바꿨는지** — 파일 단위
2. **적용한 가정과 이유** — 🔶 값을 쓴 곳은 반드시 명시
3. **확인 방법** — 어느 뷰포트(360 / 390 / 768 / 1024 / 1440px)·브라우저에서 무엇을 보면 되는지
4. **남은 이슈·제안** — 있을 때만

커밋 메시지는 Conventional Commits(`feat:`, `fix:`, `style:` …), 하나의 논리적 변경 단위로 작성합니다.
