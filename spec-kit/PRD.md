# 제품 요구사항 문서 (PRD)

## 1. 제품 개요

- **제품명:** DRAFT.X 디지털 에이전시 웹사이트
- **제품 유형:** 하이엔드 디지털 에이전시 포트폴리오 및 문의 사이트
- **브랜드 표기:** `DRAFT.X`
- **제품 목표:** 에이전시의 작업물, 제작 방식, 철학, 수상 및 서비스 단계를 소개하고 잠재 고객이 문의할 수 있도록 한다.
- **기준 자료:** `spec-kit/AGENTS.md`의 PART 3 사이트 명세. 이 문서는 사이트의 제품·콘텐츠 요구사항만 정리하며, 일반 디자인/개발 작업 규칙은 포함하지 않는다.

## 2. 대상 사용자와 주요 이용 흐름

### 대상 사용자

- 에이전시의 포트폴리오와 작업 방식을 확인하려는 잠재 고객
- 서비스 단계와 제공 범위를 비교하려는 잠재 고객
- 프로젝트 상담을 요청하려는 방문자
- 실험 작업과 아카이브를 살펴보려는 방문자

### 주요 이용 흐름

1. 홈에서 에이전시의 핵심 메시지와 선택 작업을 확인한다.
2. 작업 목록, LAB.X 갤러리, 제작 방식, 수상·고객사, 요금 정보를 둘러본다.
3. 관심이 생기면 Contact 페이지의 문의 양식을 제출하거나 카카오톡 채팅으로 이동한다.

## 3. 정보 구조 및 페이지

| 경로 | 페이지 | 주요 요구사항 |
|---|---|---|
| `/` | 홈 | 히어로, 선택 작업, 작업 쇼케이스, 제작 방식, 핵심 철학, 수상·고객사, 요금, 아카이브 및 푸터를 순서대로 제공한다. |

## 4. 공통 기능 및 콘텐츠 요구사항

### 헤더 및 공통 내비게이션

- `DRAFT.X` 로고는 홈으로 연결한다.
- 메뉴는 `Home`, `Works`, `LAB.X`, `Contact`로 구성한다.
- `2026 // GDWEB DESIGN AWARDS WINNER PRIZE` 배지는 `/work/dra`로 연결한다.
- 모바일 메뉴는 `Menu`와 `Close` 상태를 제공한다.
- 카카오톡 상담 링크를 제공한다: `https://pf.kakao.com/_ANXIX/chat`.
- 현재 페이지를 내비게이션에서 구분할 수 있어야 한다.

### 푸터

- `Top` 링크, 스튜디오 소개, 이메일, 저작권 문구를 제공한다.
- 이메일은 `draftx.co@gmail.com`을 사용한다.
- 푸터는 페이지에 한 번만 표시한다.

## 5. 홈 페이지 요구사항

홈 콘텐츠는 다음 순서를 따른다.

1. **히어로**
   - 영문 헤드라인: “10+ years of aesthetic mastery meets / high-end strategy, / delivering essential changes / for your brand.”
   - 한글 서브카피: “축적된 심미적 안목이 하이엔드 전략과 만나, 브랜드에 본질적인 변화를 선사합니다.”
   - `DRAFT.X` 워드마크와 이미지 콜라주를 표시한다.

2. **선택 작업**
   - 캡션 `© SELECTED WORKS 24/26`, `(DX. MASTERPIECE — 05)`, `STRATEGIC AESTHETICS`를 표시한다.
   - 제목 `Masterful aesthetics, strategic precision.`과 한글 카피, `SEE WORKS` 링크를 제공한다.
   - `dra`, `muk`, `arche`, `velo`, `otium`, `aur.a` 작업 카드 6개를 제공한다.
   - 첫 번째 `dra` 카드에 수상 배지를 표시한다.

3. **작업 쇼케이스**
   - `© AUR. A`, `(05. LUXURY BRANDING)`, `UNRIVALED ORIGINALITY` 캡션과 풀폭 이미지를 표시한다.

4. **제작 방식**
   - `{ High-end Digital Production }`, `How we craft essentials`, `DRAFT.X : 우리가 본질을 빚어내는 방식`을 표시한다.
   - 제목과 설명으로 이루어진 아코디언 항목 6개를 제공한다.
   - 아래 항목 문구를 사용한다.
     1. **직관과 데이터의 전략적 설계:** 20년간 축적된 심미적 직관에 AI 분석 전략을 더해, 장황한 기획 대신 브랜드에 즉각적으로 필요한 핵심 방향성만을 도출합니다.
     2. **고효율·고감도 디지털 빌드 시스템:** 제로 베이스의 비효율적 설계 대신 검증된 하이엔드 프레임워크를 기반으로 커스터마이징하여, 디자인 기획에 소요되는 시간과 비용을 혁신적으로 절감합니다.
     3. **독보적 서사를 담은 AI 비주얼 생성:** 세상에 존재하지 않는 브랜드 고유의 이미지를 AI 기술로 직접 생성하여, 기성 스톡 이미지로는 도달할 수 없는 압도적인 브랜드 서사와 몰입감을 완성합니다.
     4. **본질에 집중하는 콘텐츠 최적화:** 콘텐츠 분석부터 루틴 설계까지, 브랜드의 정체성이 디지털 환경에서 가장 강력한 힘을 발휘할 수 있도록 최적의 구현 방식을 제안합니다.
     5. **미세한 감각이 만드는 시각적 조화:** 폰트의 자간과 여백의 미세한 조정을 통해 시각적 피로도를 낮추고, 브랜드의 품격이 느껴지는 DRAFT.X만의 최상위 레이아웃을 구현합니다.
     6. **브랜드의 지속 가능한 성장 시스템:** 제작 이후에도 클라이언트가 직접 관리하고 확장할 수 있는 유연한 시스템을 제공하여, 브랜드가 멈추지 않고 지속적으로 성장하도록 돕습니다.

5. **핵심 철학**

## 6. 하위 페이지 요구사항

### Works (`/work`)

- 소제목 `works`와 태그라인 `Defining the Essence of Identity through Strategic Intelligence.`를 표시한다.
- `dra` 카드에 수상 배지를 제공한다.
- 프로젝트를 이미지 링크 카드로 표시한다. 카드 제목은 시각적으로 표시하지 않으며 필터 기능은 제공하지 않는다.
- 페이지 클로징과 푸터를 제공한다.

### LAB.X (`/lab.x`)

- 제목 `LAB.X`, 부제 `Expanding the Boundaries of Design through Continuous Technical Evolution.`, 소개 `Crafting a sanctuary of minimalism and nature`를 표시한다.
- `STUDY NO.001 ~ NO.24` 실험 갤러리를 제공한다. 각 항목은 번호, 영문 제목, 이미지로 구성한다.
- 갤러리는 가로 스크롤과 스냅을 지원한다. 자동 이동을 사용할 경우 일시정지 기능을 제공하고, reduced-motion 환경에서는 정지 상태로 시작하며 키보드 포커스 시 이동을 멈춘다.

### Contact (`/contact`)

- 제목 `Contact`, 소개 문단, `전략적 지능`을 강조한 인용 블록, 문의 양식을 제공한다.
- 입력 필드는 다음과 같다.

  | 필드 | 입력 형식 | 필수 |
  |---|---|---|
  | `Brand Name` | 텍스트 | 예 |
  | `Email` | 이메일 | 예 |
  | `Project Vision & Core Essence` | 여러 줄 텍스트 | 예 |

- 제출 버튼 문구는 `Request Strategic Definition`으로 한다.
- 각 입력 요소에는 항상 보이는 라벨을 제공하며, placeholder를 라벨 대신 사용하지 않는다.
- 제출 과정은 로딩·성공·오류 상태를 제공한다. 성공 메시지는 보조 기술에 전달되어야 한다.
- 입력 오류에는 원인과 해결 방법을 표시한다.
- 스팸 방지용 honeypot 필드를 포함한다.
- 전송 방식은 `CONTACT_ENDPOINT` 설정에 따른다. 엔드포인트가 비어 있으면 `mailto:draftx.co@gmail.com`, 설정되어 있으면 해당 엔드포인트로 전송한다.

## 7. 시각 및 반응형 요구사항

- 전체 브랜드 경험은 검정 배경의 다크 테마, 흰색 주요 텍스트, 회색 보조 텍스트를 기본으로 한다.
- 포인트 연두색은 중괄호 장식, 푸터 이메일, 강조된 요금 카드에 한정한다.
- 데스크톱 1440px 시안의 콘텐츠 폭은 최대 1440px이며 중앙 정렬한다.
- 모바일 우선으로 구성하고 태블릿·데스크톱으로 확장한다. 1440px 초과에서는 콘텐츠 최대 폭을 유지한다.
- 작업 카드 목록은 데스크톱 2열, 모바일 1열로 제공한다.
- 원본에 있는 카피와 카운트는 임의로 수정하거나 새 문구를 만들어 넣지 않는다.
- 10+ years / 20 years 문구 간 차이는 원본 그대로 유지하며 임의로 통일하지 않는다.

## 8. 접근성 및 동작 요구사항

- 페이지당 주 제목은 하나로 구성하고 섹션 제목과 항목 제목은 계층적으로 표시한다.
- 모든 링크와 인터랙티브 요소는 키보드로 사용할 수 있고 명확한 포커스 상태를 제공한다.
- 이미지에는 실제 내용을 설명하는 대체 텍스트를 제공하거나 장식 이미지는 보조 기술에서 제외한다.
- 작업 카드와 수상 배지처럼 보이는 제목이 없는 링크에도 접근 가능한 이름을 제공한다.
- 자동 재생 모션은 `prefers-reduced-motion` 설정을 존중한다. 자동 이동 콘텐츠는 사용자가 멈출 수 있어야 한다.
- 확대/축소를 막지 않는다.

## 9. 범위에서 제외하거나 확인이 필요한 항목

- `/work/[slug]` 상세 페이지의 실제 콘텐츠는 기준 자료에서 확인되지 않았으며, 별도 요구 전까지 구현 범위에 포함하지 않는다.
- 히어로의 최종 크기·배치, 헤더의 상세 표현, 아코디언 열린 상태의 세부 시각 값, 모바일·태블릿의 정확한 간격과 글자 크기는 기준 시안에서 확인되지 않았다.
- 원본의 연락처 전송 서버/외부 폼 서비스 사용 여부가 별도로 결정되지 않으면 기본 정책(`mailto` 또는 설정된 엔드포인트)에 따른다.
- 푸터 이메일은 기준 자료의 배포 원문인 `draftx.co@gmail.com`을 따른다. Figma 시안과의 이메일 불일치는 필요 시 별도 확인한다.
