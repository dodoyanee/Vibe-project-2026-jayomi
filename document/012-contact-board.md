# Contact 문의 게시판

## 화면

- `pages/contact.html`: 누구나 볼 수 있는 질문 목록, 질문 유형 필터와 검색
- `pages/contact-view.html?id={questionId}`: 질문과 관리자 답변
- `pages/contact-write.html`: 로그인 회원의 질문 작성 및 본인 문의 수정
- 문의 유형은 배송문의, 계정문의, 교환/환불, 시스템오류, 기타입니다.

비공개 질문은 목록에 제목과 잠금 표시가 보입니다. 본문과 답변은 작성자와 관리자만 조회할 수 있습니다. 질문을 삭제하면 본문과 답변도 함께 삭제합니다. 답변 등록·수정·삭제와 답변 완료 상태 변경은 관리자만 할 수 있습니다.

## Firestore 구조와 보안

- `contactQuestions/{questionId}`: 공개 목록 메타데이터와 `answered` 상태
- `contactQuestions/{questionId}/content/question`: 질문 본문
- `contactQuestions/{questionId}/answers/response`: 관리자 답변

질문 본문과 답변을 공개 목록 문서와 분리해 비공개 글 내용이 목록 조회에 포함되지 않도록 했습니다. `firestore.rules`는 문의 작성에 인증을 요구하고, 본문은 공개 질문 또는 작성자·관리자에게만 허용하며, 수정·삭제는 작성자(또는 관리자)로 제한합니다. 답변 쓰기와 상태 변경은 관리자 역할만 허용합니다. 목록에서 보이는 제목·유형·작성자 이름·날짜 및 비공개 여부는 공개 정보입니다.

기존 프로젝트에 반영할 때는 Firebase Console의 Firestore Rules에 저장소의 `firestore.rules` 전체 내용을 게시해야 합니다. 웹 앱 배포만으로 Firestore 규칙은 변경되지 않습니다. 실제 Firebase 계정/프로필을 이용한 글 작성과 권한 테스트는 규칙 게시 후 수행해야 하며, 이 작업에서는 운영 DB에 테스트 질문을 쓰지 않았습니다.

## 메인 화면 인터랙션

- 선택 작품 미디어는 스크롤 위치에 따라 섹션 진입 시 아래에서 올라오고 다음 섹션으로 이동할 때 위로 빠지는 패럴랙스 효과를 적용했습니다.
- 선택 작품 제목은 스크롤 진행에 맞춰 단어별로 회색에서 흰색으로 채워집니다.
- 포트폴리오 이미지 카드에는 반투명 VIEW 표시가 hover/focus 시 나타납니다. 기존 커스텀 커서 VIEW 동작은 유지됩니다.
- 아코디언 설명의 좌우 패딩은 유지하면서 위아래 패딩을 맞췄습니다.
- 모바일 내러티브 미디어 폭은 기존보다 15% 넓혔습니다.
