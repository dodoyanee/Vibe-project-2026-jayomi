# Section 4 — AUR. A 쇼케이스

Section 3 포트폴리오 다음에 `#showcase`를 추가했다. 검정 배경, 세 항목 캡션, 얇은 구분선, 건축 배경 이미지와 중앙 실제 영상으로 구성한다.

## 변경 파일

- `index.html`: Section 4 마크업과 전용 스타일 연결.
- `css/tokens.css`: Section 4의 색·크기·여백·이미지·반응형 토큰.
- `css/components/showcase.css`: 캡션 정렬, 배경 이미지, 영상 클리핑, 재생 버튼.
- `js/main.js`: 새 영상 모듈 초기화.
- `js/modules/showcase-video.js`: 재생·정지, 화면 밖/숨긴 탭 정지, 수동 정지 유지, 모션 감소, 로딩 실패 안내.
- `images/showcase/`: 제공된 `curr-task/004` 파일을 복사한 실행용 자산.

## 미디어

`aur-a-architecture.png`는 건축 배경, `aur-a-showcase.mp4`는 실제 웹사이트 녹화 영상이다. 원본 파일 내용은 변경하지 않았다. 녹화 파일의 해상도는 1280×704, 재생 길이는 약 11.92초다.

원본 사이트에서 확인한 내부 영상 프레임 930×610을 유지하고 `object-fit: cover`를 적용한다. 모바일에서도 영상 안의 글자·메뉴·카드는 재배치하지 않으며 바깥 프레임에서 넘치는 부분을 자른다. 캡처의 재생 장면·스크롤 캡처 중복을 별도 HTML로 복제하지 않는다.

영상은 `autoplay muted loop playsinline`을 사용한다. 브라우저 기본 컨트롤 대신 키보드·터치로 사용할 수 있는 재생/일시정지 버튼을 제공한다. 마우스 환경에서는 재생 중 미디어에 마우스를 올리거나 버튼에 포커스하면 나타난다. 터치 환경과 정지 상태에서는 표시한다. 자동 재생이 제한된 환경에서도 버튼으로 시작할 수 있다.

`prefers-reduced-motion: reduce`에서는 자동 재생을 해제하고 사용자가 직접 시작할 수 있게 한다. 화면 밖과 숨긴 탭에서는 멈추며 수동 정지 상태를 보존한다.

## 반응형과 가정

데스크탑을 기본으로 작성하고 `css/tokens.css`에서 다음 순서로 덮어쓴다.

1. 1200px 이상: 최대 콘텐츠 폭 1440px, 좌우 안쪽 여백 20px, 미디어 높이 780px.
2. `@media (max-width: 1199px)`: 태블릿, 미디어 높이 700px, 영상 상단 크롭 조정.
3. `@media (max-width: 806px)`: 모바일, 마지막 캡션 숨김, 두 항목 좌우 정렬, 별도 상단 간격과 미디어 높이 적용.

브레이크포인트와 데스크탑 우선 작성 순서는 이번 사용자 요청을 우선했다. 기존 규약 문서는 수정하지 않았다. 새 섹션의 여백·크롭 위치·모바일 높이는 첨부 캡처를 기준으로 조정한 값이며 원본 사이트 코드의 실측값으로 주장하지 않는다. 높이가 낮은 모바일 화면은 기존 고정 헤더가 캡션을 가리지 않도록 미디어 높이를 제한한다. CSS 배경 URL 토큰은 사용하는 `css/components/showcase.css`를 기준으로 상대 경로를 지정한다.

## 검증

- 로컬 브라우저에서 360 / 390 / 768 / 806 / 807 / 1024 / 1199 / 1200 / 1440 / 1920px의 너비와 두 브레이크포인트 경계를 확인했다. 모든 너비에서 가로 넘침이 없으며 모바일에서 마지막 캡션만 숨겨진다.
- 데스크탑·태블릿·모바일의 이미지와 실제 영상 표시를 시각 확인했다. 806×625에서는 미디어를 332px로 조정해 캡션이 기존 고정 헤더 아래에 표시된다.
- 브라우저에서 영상 메타데이터·재생 시간 증가·무음·반복·인라인 설정·수동 정지 유지와 콘솔 오류/경고 부재를 확인했다.
- 별도 실행 검사에서 영상 수명주기 17개 항목(화면 밖/숨긴 탭 정지, 수동 정지 유지, 모션 감소, 직접 재생, 오류 상태, 정리)을 통과했다.
- JavaScript 문법, 로컬 자산 경로, 기존 Section 1~3 보존, ZIP 무결성을 확인했다.
- 실제 iOS/Android 기기와 Lighthouse 점수는 측정하지 않았다.
