# Section 3 포트폴리오와 사이트 커서

작성일: 2026-11-05

## 변경 파일

- `index.html`: Section 2 뒤에 Section 3(`id="portfolio"`) 추가. 실제 `<a>` 링크 카드 6개, 숨김 제목과 링크 이름, `aria-hidden="true"` 장식용 커서 추가.
- `css/tokens.css`: 카드 비율·간격·모서리·구분선과 커서 규격의 디자인 토큰 추가.
- `css/components/work-grid.css`: 카드 목록의 2열/1열 배치, 행별/카드별 구분선, 이미지 위치와 키보드 포커스 표시.
- `css/components/site-cursor.css`: 흰색 원형 커서, 검은 VIEW 캡슐, 200ms 상태 전환, 입력 장치 조건과 모션 감소 설정.
- `js/modules/site-cursor.js`: 프레임당 최대 한 번의 위치 갱신, 실제 위치의 카드 감지, 입력창 기본 커서, 터치·창 이탈·비활성화 처리, 스크롤/리사이즈 시 재감지, 이벤트 정리.
- `js/main.js`: 커서 모듈 초기화.
- `images/works/`: `curr-task/003`의 6개 이미지 원본을 용도별 파일명으로 복사. 이미지에 포함된 로고·글자를 HTML로 중복 제작하지 않음.

## 디자인과 적용 기준

검정 배경(#000), 흰 커서(#fff), 검은 캡슐(#111), 회색 구분선(#262626)을 사용한다. VIEW는 기존 DM Sans 글꼴을 따른다. 별도 라이브러리·폰트·배포 설정을 추가하지 않았다.

기존 겉박스 > 속박스 > Flex 파티션 구조 안에서 목록에만 CSS Grid를 사용한다. 카드가 시각적 중심이며, 추가 제목·배지·버튼을 이미지 위에 배치하지 않는다.

```text
1200px 이상 / 807~1199px     806px 이하
[ DR.A  ]  [ MUK   ]       [ DR.A  ]
--------------------       ---------
[ Arche ]  [ VELO  ]       [ MUK   ]
--------------------       ---------
[ OTIUM ]  [ AUR.A ]       [ Arche ] → VELO → OTIUM → AUR.A
```

| 너비 | 열 | 컨테이너 최대 너비 | 내부 좌우 여백 | 열 간격 | 행/카드 간격 |
|---|---:|---:|---:|---:|---:|
| 1200px 이상 | 2 | 1440px | 40px | 40px | 65px |
| 807~1199px | 2 | 화면에 맞춤 | 28px | 24px | 48px |
| 806px 이하 | 1 | 화면에 맞춤 | 18px | 해당 없음 | 40px |

카드 비율은 1.3:1, 모서리는 12px이며 `object-fit: cover`를 사용한다. DR.A·VELO는 주요 내용이 보이도록 아래쪽으로 조금 조정하고, Arche는 상단 문구를 보존하도록 위쪽으로 정렬했다. 구분선은 1px이며 행/카드 간격 가운데 놓인다. 동일한 목록을 사용해 반응형 전환 시 순서를 유지하고 선을 중복 생성하지 않는다.

기존 문서의 임시 카드 규격·모바일 우선 작성법·모션 제한보다 이번 사용자의 명시적인 1.3:1 규격, 데스크탑 기본 스타일, 커서 상태 전환 요청을 우선 적용했다. 기존 규약 문서는 수정하지 않았다.

`curr-task/003`에는 프로젝트 이미지 6개가 있으며 별도의 커서 참고 화면은 확인되지 않았다. 따라서 커서는 사용자가 지정한 흰 원 16px, VIEW 80×44px, 글자 15px, 전환 200ms를 적용했다.

로컬 상세 페이지는 기존 프로젝트에 없으므로 프로젝트 문서에 기록된 공개 상세 URL을 사용했다. 실제 공개 Works 페이지의 카드 링크와 일치하며 6개 모두 HTTP 200 응답을 확인했다. 상세 페이지를 새로 만들지는 않았다.

## 확인 결과

Chrome에서 360, 390, 768, 806, 807, 1024, 1199, 1200, 1440, 1920, 2560px를 검수했다.

- 열 개수, 동일한 카드 너비와 1.3:1 비율, 여백, 카드 순서, 12px 모서리 통과.
- 데스크탑·태블릿 구분선 2개, 모바일 구분선 5개와 콘텐츠 폭 일치 확인. 가로 넘침 없음.
- 일반 영역의 16px 흰 원, 카드의 80×44px VIEW, 중심 좌표 유지, 이미지 내부 이동, 카드 이탈 복귀 확인.
- 정지한 포인터 아래로 스크롤하거나 화면 크기를 바꿔도 카드 상태 재감지 확인.
- 창 이탈·비활성화 시 숨김과 실제 위치 재진입 확인. 입력창에서 기본 텍스트 커서 및 입력 확인.
- 카드 전체 마우스 클릭과 Tab/Enter 이동, 명확한 흰색 포커스 표시 확인.
- 390px 모바일·1024px 태블릿 터치 모의 환경에서 커서 미표시와 한 번 탭 이동 확인.
- 390px 너비에서도 마우스 환경이면 커스텀 커서가 활성화되어 너비와 장치 조건이 분리됨을 확인.
- `prefers-reduced-motion: reduce`, 커서 CSS 로드 실패 시 기본 커서 유지, JavaScript가 꺼졌을 때 카드·링크 보존 확인.
- `pagehide` 이벤트 정리와 `pageshow` 복귀 확인. 새 JavaScript 실행 오류 없음.
- 기존 CDN 접근을 끊은 기본 스크롤과, GSAP·ScrollTrigger·Lenis·웹폰트를 모두 로드한 기존 스크롤 환경에서 검수 완료.

터치 조작은 Chrome의 장치 모의 환경으로 확인했으며 실제 iOS/Android 기기와 Safari 실기기 검수는 수행하지 않았다. 기존 전체 사이트의 Lighthouse 점수는 이번 범위에서 측정하지 않았다.

## 실행

압축을 풀고 프로젝트 폴더를 VS Code Live Server 등 정적 HTTP 서버로 연다. `/#portfolio`로 Section 3에 바로 접근할 수 있다. 기존 ES Modules 방식을 사용하므로 로컬 HTTP 서버에서 확인한다.

원본 프로젝트 폴더는 변경하지 않았다. ZIP에는 기존 파일·참고 자료와 수정된 소스 전체가 포함되어 있으며 `.git`은 제외했다.
